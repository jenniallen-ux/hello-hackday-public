# helloworld
first drop on new gmail linked account

## Alex's First Card
`credit-card-adventure.html` – a choose-your-own-adventure about a 19-year-old's first credit card. Six monthly decisions update a live dashboard (balance, interest & fees, credit health), each followed by a short "why this happened" tip. Open the file in a browser; no build step. Numbers are illustrative only.

## Build My Plan
`build-my-plan.html` – a short guided flow that turns credit-building understanding into a plan: choose a regular bill to move onto the card (with a live utilisation meter), choose how to repay (with a six-month projection), set reminders and alerts, then review and confirm. Numbers and the healthy range are illustrative.
